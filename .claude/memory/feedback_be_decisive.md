User: "you think too much. i don't know how to turn that off." Said after a long autonomous fix→commit→rebuild→test→commit→fire chain where the user lost the thread and had to interrupt.

**Two things:**
1. **Less visible deliberation.** Don't narrate every option, weigh reversible calls out loud, or hedge. Pick the sensible default and act. Terse report after, not a play-by-play. (Reinforces [[feedback_yap_less]].)
2. **Checkpoint before big/outward moves in a long chain.** Doing 6 things in a row and ending with a day-long campaign launch = the user loses track. Pause and surface state before the consequential action, especially launches/deploys ([[feedback_user_drives_button]]). Prefer small/validating steps first (user: "i'd run a smaller campaign that ends quickly, then let it actually run").

**How to apply:** act on defaults for small reversible steps; stop and show state before the big irreversible/expensive one. Keep responses short — change-and-why, then stop.
